# 派生版本变更记录

> 本文件记录派生仓库相对上游 [CHANGELOG.md](CHANGELOG.md) 的**新增**内容。
> 上游变更记录原样保留、未修改。

## v0.3.0-dingtalk — 2026-10-16（本仓库新增）

在上游 v0.2.0 基础上新增钉钉适配层与消息到待办的智能转换，QQ / 微信与桌面待办组件原样保留。

### 钉钉消息读取（新增）

- 新增 `dingtalk_probe.py`：阶段 0 只读探针，V3 本地库离线解密 + SQLite 一致性校验 + 表结构验证，运行前硬阻断网络与后台线程。
- 新增 `dingtalk_export.py`：钉钉群聊文本按需导出，仅群聊（`type=2`）、仅文本（`contentType=1`）、需 `--confirm`；单聊与未知群硬拒绝。
- 密钥由 `uid + user_config 盐值` 离线推导（PBKDF2-HMAC-SHA1 → MD5 → AES-128-ECB），无需内存扫描。

### 消息到待办（新增）

- 新增 `todo_import.py`：已导出文本逐条写入待办，稳定 ID `dingtalk:<cid>:<mid>`，幂等且保留完成/移除状态。
- 新增 `todo_tasks.py`：任务级管线——筛选含行动要求的消息，同任务多消息合并为一条记录，不同任务分别建立待办；保留每条消息的完整来源。

### 工程化

- 新增 `tests/test_dingtalk_pipeline.py`：覆盖行动筛选、任务合并、稳定 ID、溯源完整性与范围守卫。
- 新增 `NOTICE-ADDENDUM.md`：声明派生新增部分的技术参考与许可证。
- 新增桌面快捷方式创建脚本与多尺寸图标（方案一：气泡 + 勾选）。
