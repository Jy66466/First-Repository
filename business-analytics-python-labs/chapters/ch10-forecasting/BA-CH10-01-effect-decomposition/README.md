# BA-CH10-01 效应分解：AirPassengers 与节日效应

实验用 Python 复现教材“效应分解法”中可独立验证的部分：

1. **对数变换**：月度序列取自然对数（对应教材 `ln_AIR` 列）；
2. **乘性经典分解**：12 期中心化移动平均估计趋势，按同月平均估计并
   归一化季节指数，余项为分解残差，满足 `趋势 × 季节 × 余项 ≈ 原序列`；
3. **节日效应**：以节日日均值与非节日日均值的差估计效应并扣除
   （对应教材“含节日/去除节日”对比思路）；
4. **季节朴素预测**：以最近完整周期同月观测值作为预测的原创基线。

```powershell
python run_effect_decomposition.py --input "<air.csv or xlsx>" --date-column DATE --value-column AIR
python -m pytest -q
```

## 验证边界（重要）

- **WPS 自带 AI 预测**（`*_WPS自带AI功能做时间序列预测.xlsx`）为黑盒
  算法，无法从文件还原其模型；本实验不模拟、不对比其预测值；
- **效应分解法.pbix** 的内部度量与变换未验证，属 P1.3 Power BI 专项；
- 教材“信用卡消费额”系列为聚合日度数据，本实验以合成数据演示节日
  效应口径，不复制、不发布原始序列。

## 口径说明

- 季节指数按乘性模型估计：`指数 = 同月(原值/趋势)均值`，并以 12 个月
  均值归一化为 1；
- 趋势为偶数周期中心化移动平均（权重 `[0.5,1,...,1,0.5]/12`），序列
  首尾各 6 期无趋势值；
- 预测基线明确命名为 `seasonal_naive_forecast`，不代表教材方法。
