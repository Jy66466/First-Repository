# BA-CH01-02 输入说明

运行入口需要两份已获授权的本地工作簿副本（教材资料，不随实验发布）：

| 参数 | 对应教材工作表 | 结构要点 |
| --- | --- | --- |
| `--fact` | `产品销售数据表` | A1:I13741；`销售额` 为公式列 `=数量×单价`；产品编号大小写混用 |
| `--product` | `产品信息表` | A1:F10；产品编号大写，含采购单价与销售单价 |

可选维度（核心逻辑已内置，命令行入口暂只读前两份以控制演示范围）：

- `商铺城市`：城市编码 ↔ 城市名称；
- `日期表`：732 天日期维度。

自动化测试使用人工构造的星型模型数据（3 行事实 + 3 个产品），不依赖教材工作簿。
