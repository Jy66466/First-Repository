# BA-CH01-02 维度模型演示：商场销售数据

实验用 Python（pandas + SQLite）复现教材“维度模型”演示的星型模型：
以产品销售数据表为事实表，产品信息、商铺城市、日期为维度表，演示
粒度定义、键规范化、一致性校验与星型连接聚合。

```powershell
python run_dimension_model_demo.py --fact "<fact.xlsx>" --product "<product.xlsx>"
python -m pytest -q
```

## 口径说明

- 事实粒度为“日期 × 城市 × 产品 × 单据行”，度量为 `销售数量` 与
  `销售额 = 销售数量 × 销售单价`；
- 事实表产品编号存在大小写混用（`a001` / `A001`），连接前统一大写；
- 事实表冗余携带的品牌/类别列以事实表为准，维度表只补充缺失属性和
  用于单价一致性校验；
- 聚合口径为直接求和（数量、销售额），不做平均分摊。

## 教材数据特征记录（不修改原始数据）

- 事实表 12,960 行中有 **2,075 行**的销售单价与产品信息表目录价不一致：
  B002 MD电视 1,531 行（事实 3599 vs 目录 4299）、C003 HE洗衣机 544 行
  （事实 4669 vs 目录 4699）。事实表销售额与自身单价一致，符合“事实表
  记录成交价、维度表记录目录价”的建模口径；教材正文缺失，无法确认是
  教学脏数据还是促销价，实现保留该差异、不迁就任何一侧；
- 工作簿缓存中有 **4 行**（2018-10-01 两行、2019-11-16 两行）的销售额
  不等于本行数量×单价，数值呈跨行错位特征，视为工作簿内部异常保留；
- 本实验不修改上述任何教材原始数据，也不发布原始工作簿。

## 验证边界

- 本实验仅完成 Excel 侧（星型结构、键规范化、聚合）的验证；数据来源为
  本地已获授权的教材工作簿只读副本，验证结果不外推到 Power BI；
- 教材同名 PBIX 的模型关系、基数和筛选方向**未验证**，属于 P1.3
  Power BI 专项范围，本实验不宣称复现 Power BI 语义。
