# BA-CH02-12 桑基图：流向数据计算

教材桑基图实验的桑基视觉对象为第三方自定义视觉（SankeyDiagram.pbiviz），
其渲染属于 Power BI 运行时行为。本实验迁移的是经实测验证的**流数据计算**：

1. **边表规范化**：校验“来源/目标/流量”结构、正值流量、无自环；
2. **节点流汇总**：每节点的流出、流入与净流量；
3. **层级计算**：入度为 0 的节点为 0 层，其余为 max(前驱层级)+1（含环检测）。

```powershell
python run_sankey_flow.py --input <flows.xlsx or csv> --sheet 0
python -m pytest -q
```
