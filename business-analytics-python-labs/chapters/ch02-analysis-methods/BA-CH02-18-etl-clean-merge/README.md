# BA-CH02-18 ETL：清洗、拆分、纵向/横向合并

实验用 Python（pandas）复现教材 Power Query 演示的四类 ETL 操作：

1. **拆分列**：把按逗号分隔的多订单号一列拆成多行；把 `8件` 这类“数值+单位”文本拆成数值列与单位列。
2. **数据清洗**：删除标题行与占位空行、去重、`#N/A` 等占位符统一为缺失值、文本金额转数值。
3. **纵向合并（追加）**：字段名称一致直接拼接；字段名称不一致时先按映射重命名对齐再拼接。
4. **横向合并**：按键连接课程表、选课表、学生表（等价 SQL JOIN）。

```powershell
python run_etl_clean_merge.py --input "<authorized.xlsx>" --header-row 1
python -m pytest -q
```

## 口径说明

- 清洗规则以教材演示数据结构为准（标题行、空行、`#N/A`、文本金额），见 `src/etl_clean_merge/core.py` 模块说明；
- 纵向合并以左表（第一季度）的列名为准，右表不一致列必须显式提供重命名映射；
- 横向合并默认左连接，未匹配键保留并置 NA；
- 教材的 Power Query 步骤顺序不可从文件名推断，本实验按上述已声明规则实现并逐条测试。

## 已知限制

- 原工作簿（电商订单、课程选课等演示数据）属于教材资料，不随本实验发布；运行入口需要使用者提供已获授权的本地副本；
- IP 列的非法取值仅标记为缺失，不做地理或格式修复；
- 本实验不涉及 Power Query 的高级步骤（如条件列、逆透视），对应内容未在教材文件中提供稳定口径。
