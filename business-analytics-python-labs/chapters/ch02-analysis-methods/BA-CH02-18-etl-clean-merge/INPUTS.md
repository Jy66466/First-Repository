# BA-CH02-18 输入说明

本实验的输入为教材 ETL 练习工作簿（5 个演示文件）。这些文件属于教材资料，
**不包含在本实验目录中，也不得同步到公开仓库**；运行演示时使用本地已获授权的只读副本。

| 演示场景 | 工作簿（本地路径自行指定） | 结构要点 |
| --- | --- | --- |
| 拆分列 | `拆分列示例数据.xlsx` | Sheet2，2 行数据；`订单号` 列含逗号分隔的 3 个值；`数量` 列为“数值+单位” |
| 数据清洗 | `数据清洗示例数据.xlsx` | sheet1 首行为报表标题、次行为字段名，含空行与 `#N/A`；`实付金额` 为文本 |
| 纵向合并（字段一致） | `纵向合并演示-各字段名称一致.xlsx` | `第一季度`/`第二季度` 两表字段完全一致，各 4 行数据 |
| 纵向合并（字段不一致） | `纵向合并演示-字段名称不一致.xlsx` | `第二季度` 的 `销售额` 列名为 `金额`，需重命名对齐 |
| 横向合并 | `BI横向合并练习文件 .xlsx` | `课程表`/`学生表`/`选课表` 三表，按 `课程号`/`学号` 连接 |

## 运行入口参数

```powershell
python run_etl_clean_merge.py --input <cleaning-demo.xlsx> --header-row 1 --output outputs/etl_summary.json
```

- `--input`：清洗演示工作簿路径（本地授权副本）；
- `--header-row`：字段名所在行（0 起），演示数据为 1；
- 输出为清洗前后行数与金额合计的 JSON 摘要，不输出任何原始数据行。

自动化测试全部使用人工构造数据，不依赖上述工作簿。
