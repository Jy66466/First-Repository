# BA-CH02-01 波士顿矩阵

本实验把品牌在两个期间的销售额转换为市场份额和销售增长率，并按波士顿矩阵分组。工作簿证据显示，市场份额使用两个期间合计销售额，占比阈值为品牌平均份额；增长率使用两个期间环比，阈值为总体市场环比。

Python 先计算 `销售额=单价×销量`，再独立聚合。份额和增长率都严格大于阈值才进入高组，等于阈值归低组。输出包含品牌级结果，但 CLI 写出的 JSON 只保留品牌数量和类别计数；公开仓库不包含教材数据或参考答案。

```powershell
python run_boston_matrix.py --input "<authorized.xlsx>" --base-period 2019-07 --comparison-period 2019-08
python -m pytest -q
```
