# Input Data

Provide a local workbook containing paired numeric observations in columns `x` and `y`. Select the worksheet with `--sheet` when it is not the default. Rows are paired by position and retained as provided; missing, non-numeric, or non-finite values are rejected rather than silently dropped.

The source workbook and any answer workbook are not included. Use only data you are authorized to process. For public demonstrations, use synthetic or separately licensed data. Tests use hand-constructed synthetic observations.
