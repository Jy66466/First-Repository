# BA-CH02-03 用户忠诚度模型

实验包含两个相互独立的客户分层：最近 13 周行为用于识别潜在用户和易流失用户；排除这两类后，再按不同订单数和消费金额的四分位阈值进行忠诚度评分。

- 潜在用户：截止日前 13 周以前无订单，最近 13 周恰有 1 个不同订单。
- 易流失用户：最后消费日期严格早于最近 13 周起点。
- F、M 小于第一四分位数记 1 分，大于第三四分位数记 3 分，其余记 2 分。
- 总分 6/5/4/2-3 分依次对应忠诚、进阶、普通、低价值用户。

```powershell
python run_customer_loyalty.py --input "<authorized.xlsx>" --analysis-date 2021-01-01
python -m pytest -q
```

CLI 只写出聚合数量和阈值，不输出会员编号。分层规则来自工作簿可核验公式，不代表对客户价值或流失原因的因果判断。
