# BA-CH03-02 财务费用分析

## 实验目标

比较两个期间的费用总额和分类费用，计算各类别的金额变化，并分析管理费用项目的环比变化。本项目实现通用的期间汇总和对照逻辑，不包含任何源数据或答案表。

## 分析口径

- 按年份、月份和类别汇总金额。
- 差额 = 比较期金额 - 基期金额。
- 环比增长率 = 差额 / 基期金额；基期为 0 时增长率未定义，输出为空。
- 同一类别/期间的多行金额求和，不自动去重。
- 未出现的类别/期间组合按 0 计算。仅在源数据能确认类别清单完整时使用该规则。
- 分类金额与单独提供的期间总额进行独立调节检查，不自动调整任何一方。

金额按输入单位精确比较；增长率容许 `1e-12` 的浮点舍入误差。使用不同精度的数据前，应根据其单位另行确定容差。

## 实现与运行

`src/expense_analysis/core.py` 完成输入校验、分类汇总、差额/增长率计算和调节检查。参考结果读取逻辑仅用于计算后的本地对照，不参与生成结果。命令行输出只含汇总状态，不写出来源行。

Python 3.10+，依赖 pandas 和 openpyxl；测试使用 pytest。数据文件由使用者在本地提供，不随项目分发。

```powershell
python run_expense_analysis.py `
  --input "<authorized-local-workbook.xlsx>" `
  --base-period 2020-06 `
  --comparison-period 2020-07 `
  --output outputs\expense_summary.json

python -m pytest
```

## 已知限制

在本地验证的案例中，两个比较期间的分类费用合计均与单独提供的总额不一致。程序保留差异并报告，不通过修改输入或删除记录来调平。该差异原因尚未确认；结果不用于推断费用是否合理或变化原因。

使用者必须确认输入数据具有处理授权。项目不包含教材、答案、客户明细或案例数据，也不为外部材料提供许可。
