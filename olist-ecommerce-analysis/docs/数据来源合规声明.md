## 一、数据源名称
Brazilian E-Commerce Public Dataset by Olist（巴西电商公开数据集，发布方：Olist）。

## 二、数据源 URL
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## 三、获取方式
通过 Kaggle 官方 CLI 或官方网页 Download 按钮下载官方发布的 ZIP 压缩包并解压。**未使用任何网页爬取、接口抓取或模拟登录手段。**
数据集版本：Version 2（2021-10-01 发布）。文件清单：9 个 CSV，合计 52 列，约 126,186,995 字节。
